## 🧠 2.4 EXEMPLO DE LÓGICA (SIMPLIFICADA)

### Cálculo de produtividade:

* NDVI médio → biomassa
* Biomassa → produtividade estimada

Exemplo:

* Área: 100 ha
* NDVI médio: 0.78
* Produtividade estimada: 3 ton/ha

➡️ Produção estimada: 300 toneladas

---

## 💻 2.5 EXEMPLO DE CÓDIGO (BASE MVP)

```python
import ee
import numpy as np

ee.Initialize()

# Região de interesse
roi = ee.Geometry.Rectangle([-55, -12, -54, -11])

# Imagem Sentinel-2
image = ee.ImageCollection("COPERNICUS/S2") \
    .filterBounds(roi) \
    .filterDate('2024-01-01', '2024-03-01') \
    .median()

# NDVI
ndvi = image.normalizedDifference(['B8', 'B4'])

# Média NDVI
mean_ndvi = ndvi.reduceRegion(
    reducer=ee.Reducer.mean(),
    geometry=roi,
    scale=10
)

ndvi_value = mean_ndvi.getInfo()['nd']

# Estimativa simples
productivity = ndvi_value * 4  # fator empírico
area_ha = 100

estimated_production = productivity * area_ha

print("Produção estimada:", estimated_production)
```
