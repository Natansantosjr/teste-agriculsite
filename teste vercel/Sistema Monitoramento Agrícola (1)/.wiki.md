# Project Summary
The **Cambuí Online** project is a web application aimed at improving agricultural monitoring and decision-making through AI. It enables users to analyze agricultural data effectively, providing features such as user authentication, role-based access for different user roles (administrators, managers, auditors), and compliance with cybersecurity standards. The platform includes a public landing page, client management for legal entities (PJ), and robust data protection measures, positioning it as a vital tool for agricultural stakeholders.

# Project Module Description
The project comprises several functional modules:
- **User Authentication**: Manages user login and role-based access.
- **AI Prediction**: Employs machine learning to deliver agricultural data predictions.
- **Geospatial Data Analysis**: Visualizes and analyzes geospatial agricultural data.
- **User Profile Management**: Manages user information and permissions based on roles.
- **Location Filtering**: Enables users to select regions, states, and cities for customized data analysis.
- **Client Management**: Facilitates CRUD operations on PJ clients and oversees subscription plans for administrators.
- **Security Audit**: Monitors system security and compliance with LGPD through audit logs.
- **Login Page**: The entry point for user authentication, allowing role selection (ADM, Gerente, Fiscal).
- **Error Handling Pages**: Manages pages for handling authentication errors and logout callbacks.

# File Description Inventory
- **backend/**: Contains server-side logic, including database models, API routes, and business logic.
- **frontend/**: Contains client-side code, including UI components, pages, and state management.
- **frontend/src/pages/LandingPage.tsx**: Public landing page for the Cambuí Online platform.
- **frontend/src/pages/AdminClients.tsx**: Admin page for managing PJ clients with CRUD functionality.
- **frontend/src/pages/SecurityAudit.tsx**: Dashboard for monitoring security audits and compliance.
- **frontend/src/pages/Login.tsx**: Login page allowing users to select their role (ADM, Gerente, Fiscal) and now checks for user authentication before displaying the role selection.
- **frontend/src/pages/LogoutCallbackPage.tsx**: Page for handling logout callbacks.
- **frontend/src/pages/AuthError.tsx**: Page for handling authentication errors.
- **frontend/src/components/Sidebar.tsx**: Navigation sidebar with updated admin menu items.
- **frontend/src/lib/retry.ts**: Utility for API calls with retry logic to handle transient errors.
- **frontend/src/App.tsx**: Main routing configuration, directing the root URL to the Login page and managing protected routes.

# Technology Stack
- **Backend**: Python, FastAPI, SQLAlchemy
- **Frontend**: React, TypeScript, Tailwind CSS
- **Database**: PostgreSQL

# Usage
To get started with the project, follow these steps:

1. **Install dependencies**:
   ```bash
   cd app/backend
   pip install -r requirements.txt
   cd ../frontend
   pnpm install
   ```

2. **Build the frontend**:
   ```bash
   cd frontend
   pnpm run build
   ```

3. **Run the backend**:
   ```bash
   cd backend
   uvicorn main:app --reload
   ```

4. **Launch the frontend**:
   ```bash
   cd frontend
   pnpm run start
   ```
